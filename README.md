# Dokdisteformidling
Dokdisteformidling produserer avtalemelding for distribusjon av forsendelser til Trygderetten via DPO (Digital post til offentlig virksomhet).

Selve sending og kvitteringshåndtering utføres av [qdist015 på dokdistdpo](https://confluence.adeo.no/spaces/BOA/pages/419525817/QDIST015+-+DistribuerForsendelseTilDPO).
