# Dokdisteformidling

Dokdisteformidling produserer avtalemelding for distribusjon av forsendelser til Trygderetten via DPO (Digital post til offentlig virksomhet).

Selve sending og kvitteringshåndtering utføres av [qdist015 på dokdistdpo (Nav-internt)](https://confluence.adeo.no/spaces/BOA/pages/419525817/QDIST015+-+DistribuerForsendelseTilDPO).

## API

JMS grensesnitt:
* [QDIST013 - Distribuer forsendelse til Trygderetten (Nav-internt)](https://confluence.adeo.no/display/BOA/QDIST013+-+DistribuerForsendelseTilTrygderetten?src=contextnavpagetreemode)

## Komme i gang

Kjør tester og bygg appen

```
mvn clean verify
```
